# Native Plant Care Signs

Printed care signs for 151 native plants of the Capital Region of New York, each
with a QR code that opens an interactive page on your phone — growing
conditions, fun facts, wildlife value, planting guide, and detail photos.

**Start here:** [ailula.top/plant-care-signs/](https://ailula.top/plant-care-signs/)

- [All plants](https://ailula.top/plant-care-signs/plants/) — searchable listing
- [Browse by purpose](https://ailula.top/plant-care-signs/guides/rain-garden/) — rain garden, shade, deer resistance, pollinators and more

## Features

- Interactive card-flip design with plant info on the back
- Search and filter all 151 plants
- Save your favorite plants to "My Plants" collection
- Detail photos from iNaturalist research-grade observations
- Seasonal planting tips based on current month

## Paths

| Path | What it is |
|------|------------|
| `plants/` | Canonical, organization-neutral plant pages |
| `guides/` | Browse-by-purpose listings |
| `wildones/` | Wild Ones Capital Region NY edition — the printed cards' QR codes point here, so these URLs are permanent |
